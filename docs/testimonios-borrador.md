# Opiniones de clientes: borradores para aprobar

Estos textos **no están publicados**. Mándale a cada cliente el suyo y pídele que lo apruebe, lo cambie o
lo reescriba con sus palabras. Publica solo la versión que el cliente confirme, con su nombre y cargo reales
(y su permiso para usarlos).

Mensaje sugerido para enviar:

> Hola, estamos preparando la web de Lumen Studio y nos encantaría incluir una frase tuya sobre el proyecto.
> Te dejo un borrador: cámbialo todo lo que quieras o escríbelo a tu manera. ¿Nos das permiso para
> publicarlo con tu nombre y el de tu negocio?
